# UNMAPPED ML Server

This is the machine learning backend for the UNMAPPED Protocol. It exposes predictive models and natural language processing pipelines through a FastAPI RESTful interface.

## 🚀 Server Setup & Startup

### Requirements
- **Python 3.12** is strictly required. Ensure you are using the correct Python version before creating the virtual environment.

### Steps to Run Locally

1. **Install Python 3.12**
   Download using
   ```powershell
   Start-Process "https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe"
   ```

2. **Create the Virtual Environment**
   From the root folder of the repository, create a virtual environment:
   ```powershell
   py -3.12 -m venv .venv
   ```

3. **Activate the Virtual Environment**
   From the root folder of the repository, activate the existing virtual environment:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. **Navigate to the ML Server Directory and Download the en_skillner model**
   Move into the `apps/ml_server` folder:
   ```powershell
   cd apps/ml_server
   ```
   Download the en_skillner model:
   ```powershell
   python -c "import urllib.request; print('Downloading en_skillner model (587 MB)...'); urllib.request.urlretrieve('https://huggingface.co/nestauk/en_skillner/resolve/main/en_skillner-any-py3-none-any.whl', 'local_models/en_skillner-0.0.1-py3-none-any.whl'); print('Download complete!')"
   ```

5. **Install Requirements**
   Install the Python dependencies listed in `Requirements.txt`:
   ```powershell
   pip install -r Requirements.txt
   ```

6. **Start the Uvicorn Server**
   Start the FastAPI server using the virtual environment's Python module. Do **not** run just `uvicorn` as it might default to the global path.
   ```powershell
   python -m uvicorn api.Main:app --reload --port 8000
   ```

Once started, the interactive API documentation (Swagger UI) is available at:
👉 **http://localhost:8000/docs**

## 📡 Endpoints

### 1. Extract Skills
`POST /api/skills/extract`

**What it does:**
Accepts informal text descriptions (like a CV snippet, a user's self-description, or work experience) and uses Natural Language Processing to extract core skills. The extracted skills are then standardized by mapping them directly to the official **ESCO (European Skills, Competences, Qualifications and Occupations)** taxonomy.

**How to call it:**
```json
{
  "texts": [
    "I have experience in Python programming, data analysis, and I am great at teamwork."
  ]
}
```

**What it returns:**
```json
{
  "results": [
    {
      "text": "I have experience in Python programming, data analysis, and I am great at teamwork.",
      "skills": [
        {
          "raw": "Python programming",
          "mapped": "Python (computer programming)"
        },
        {
          "raw": "data analysis",
          "mapped": "data analytics"
        }
      ]
    }
  ]
}
```

**How to interpret the data:**
- **`raw`**: The exact phrasing used by the user.
- **`mapped`**: The standardized ESCO term. This canonical version is what should be used downstream to index the user, issue badges, or perform semantic matching against job opportunities.

### 2. Assess Automation Risk
`POST /api/risk/assess`

**What it does:**
Calculates an individual's "Automation Risk Score" (0 to 100) based on their location and their occupation's exposure to Generative AI. 
It combines dynamic econometric data from the World Bank (e.g., broadband penetration, GDP) with ILO GenAI occupational exposure indices to predict the systemic automation risk using a trained Scikit-Learn `GradientBoostingRegressor`.

**How to call it:**
```json
{
  "country_code": "KEN",
  "extra_features": {
    "ilo_genai_exposure": 0.65
  }
}
```

**What it returns:**
```json
{
  "risk_score": 42.5,
  "indicators": {
    "broadband_penetration": 2.4,
    "internet_users_pct": 22.5,
    "ilo_genai_exposure": 0.65
  },
  "explanation": [
    {
      "feature": "ilo_genai_exposure",
      "weight": 25.1
    },
    {
      "feature": "internet_users_pct",
      "weight": -10.5
    }
  ]
}
```

**How to interpret the data:**
- **`risk_score`**: The overall calculated automation risk metric. A higher score means the individual's livelihood is more susceptible to disruption from Generative AI and automation technologies.
- **`indicators`**: The raw World Bank demographic and infrastructure metrics pulled dynamically for the provided `country_code` via `wbgapi`.
- **`explanation`**: Generated by **LIME (Explainable AI)**. It shows exactly *why* the model gave that score. Positive weights increased the risk score (e.g. high exposure), while negative weights decreased the score (e.g. low digital infrastructure preventing GenAI rollout in that region).

### 3. Issue Open Badge
`POST /api/badges/issue`

**What it does:**
Packages the user's verified and standardized skills into a cryptographically compliant **Open Badges 3.0 (JSON-LD)** credential using the `pyopenbadges` library. This ensures data portability, allowing users to own their verified skill profiles.

**How to call it:**
```json
{
  "recipient_name": "Jane Doe",
  "recipient_id": "did:example:user123",
  "skills": [
    {
      "name": "Python (computer programming)",
      "description": "Demonstrated through NLP mapping"
    }
  ],
  "badge_name": "UNMAPPED Skills Passport",
  "badge_description": "Verified skills profile generated by the UNMAPPED protocol."
}
```

**What it returns:**
A fully compliant JSON-LD Verifiable Credential object inside the `credential` envelope.
```json
{
  "credential": {
    "@context": [
      "https://www.w3.org/2018/credentials/v1",
      "https://purl.imsglobal.org/spec/ob/v3p0/context.json"
    ],
    "id": "https://unmapped.example.com/credentials/uuid",
    "type": ["VerifiableCredential", "OpenBadgeCredential"],
    "issuer": {
      "id": "https://unmapped.example.com",
      "type": "Profile",
      "name": "UNMAPPED Issuer"
    },
    "issuanceDate": "2026-04-26T00:00:00Z",
    "credentialSubject": {
      "id": "did:example:user123",
      "type": "AchievementSubject",
      "achievement": {
        "id": "https://unmapped.example.com/achievements/uuid",
        "type": "Achievement",
        "name": "UNMAPPED Skills Passport",
        "description": "Verified skills profile generated by the UNMAPPED protocol.\n\nSkills: Python (computer programming) – Demonstrated through NLP mapping"
      }
    }
  }
}
```

**How to interpret the data:**
The returned `credential` block is portable. It can be stored in the user's digital wallet, uploaded to standard credentialing networks (like LinkedIn), or verified independently by third-party services that support the Open Badges 3.0 specification.
